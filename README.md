# Radken Tech website

Public website for Radken Tech — IT proposals, policies and specs for schools, clinics and small businesses in Tanzania and Kenya. A 🇹🇿/🇰🇪 switch in the header (or `?ke` in the link) shows Kenyan prices (KES) and the Kenya contact, Simon Kimani.

- `index.html` — the whole site (English & Kiswahili), including the requirements form (sends via WhatsApp or email; no server needed)
- `img/` — service photos

Live at https://radken-tech.github.io — hosted with GitHub Pages from the `main` branch.
