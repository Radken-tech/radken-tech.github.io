# Social media images

Images for Radken Consolidated posts on LinkedIn, Instagram and Facebook.
Posts are scheduled through Buffer, which needs a public image link, so each
image here is served at:

https://radken-tech.github.io/social/img/<file name>

Name files `YYYY-MM-DD-short-name.jpg` (JPEG, 1080x1350 or 1080x1080).

## Brand
- `brand/radken-mark.svg`: the official Radken Consolidated logo mark (connected "R", gold on navy).
  Every post image and video uses this exact mark top-left, next to the wordmark RADKEN / CONSOLIDATED.
- `brand/radken-profile-1080.png`: profile picture for the LinkedIn, Instagram and Facebook pages.
