# Social media images

Images for Radken Consolidated posts on LinkedIn, Instagram and Facebook.
Posts are scheduled through Buffer, which needs a public image link, so each
image here is served at:

https://radken-tech.github.io/social/img/<file name>

Name files `YYYY-MM-DD-short-name.jpg` (JPEG, 1080x1350 or 1080x1080).
